Limitations, stated up front

  • This run is synthetic. The link between features and shortages is planted by the generator, so the scores are signal recovery, not a claim about real medicines. The framing for any interview is exactly that.
  • Persistent alerts, not a countdown. The score behaves like a standing risk register. Chronically single sourced drugs sit above the threshold for long stretches, so lead time clusters near the top of the watch window. The operational value is prioritization for dual sourcing, not a precise date.
  • Real feeds are partial. openFDA and Drug Shortages Canada carry shortage events, not supplier counts or market share. Two of the strongest features here (single supplier, HHI) need a manufacturer source join before a real data run. That join is documented, not done.
  • Undetectable by design. A first ever shortage with no supply deterioration and no category signal has nothing for the model to read, and will be missed. Missed cases are counted openly: {{ lead.missed }} of {{ lead.test_onsets_total }} test shortages.
  • Precision is modest by choice. At the F1 optimal threshold the model trades precision for recall. The precision recall curve above lets a user pick a stricter operating point.
